# Psi terminal design

## Context and theme

A developer works for hours in their existing terminal, often through long evening benchmark sessions. Psi inherits that terminal's background and font, preserving its configured ambient-light contrast and text size.

## Color

Restrained. The default sage accent, `oklch(68% 0.105 162)`, identifies Ψ, active selections and links. `/settings` offers five other restrained presets and custom hex/OKLCH colours; changes update the interface and logo immediately. Default foreground supplies body text; terminal dim supplies secondary text. Red always accompanies a written failure label. No background fill. Explicitly enabled OVERKILL adds a traveling luminance wave in the selected accent to the input borders; the quota meter uses the same accent.

## Typography

Use the terminal's configured monospace font. Bold distinguishes product and picker titles. A compact, shaded Ψ mark (12 columns by 4 rows), rendered from a small extruded mesh, brands the workspace. Keep the nearby Psi wordmark and workspace path compact. Omit startup marketing/help copy.

## Layout

A fullscreen terminal viewport contains the workspace header, a scrolling conversation and inline selection panel. The multiline prompt is pinned to the bottom on startup, during output and through resizes. Show the current chat name immediately above the session working directory beside the logo. At narrow widths use the compact identity with name and path on separate rows, shortening paths from the left. Task-named subagent status rows sit below the usage bar while active. OVERKILL enables model-directed delegation rather than launching workers at prompt submission. Require a unique descriptive name of one to five words for each assignment, without role suffixes or repeated prompt prefixes. Worker tasks are unrestricted by researcher/reviewer roles. Hide finished rows immediately without deleting saved records or reports. Show up to three rows, with overflow counted, active tool/status, short model name and elapsed time. The first row beneath the editor shows the model on the left and the bare effort value aligned to the right, with no provider label. A second row shows the active account name. Subscription accounts display only reported usage windows (5h/7d when supplied), omitting absent/unlimited windows. Metered API accounts display the current session cost, or cost unavailable when pricing is unknown. Place the clickable PLAN/EXECUTE control at the right edge of the top input border. Keep draft and slash completion at their native full width without a left gutter. Mode changes produce no conversation messages. The solid accent bottom meter prefers an actual reported five-hour quota, then a weekly or other valid quota. It fills according to percent left: 100% is unused and 0% is exhausted. Only the weekly quota stays beside the account name, avoiding duplication of the five-hour meter; the bar itself shows only the percent left. When no quota exists, clearly label the fallback as estimated goal work remaining. Conversation scrolling and selection use the terminal renderer; the visible document returns to shell scrollback on exit. Pickers filter immediately and expose keyboard hints. Narrow widths truncate metadata before primary actions. Tool results show short previews, with full results in session artifacts.

## Interaction

Shift+Tab toggles PLAN/EXECUTE. /model and account pickers keep focus in the real composer for live filtering, restore drafts and never submit search text. Account descriptions show reported reset countdowns and credit counts; narrow layouts expose the selected row details beneath the list. Picker rows show only shortened names; route IDs remain internal. Collapse duplicate display names in current-provider/connected-provider order, with hidden route fields still searchable. Escape restores the prior draft, callbacks and completions. The dedicated /effort slider uses arrows to adjust, Tab to stage OVERKILL, Enter to apply and Escape to discard. /stats uses a compact bottom panel with calendar heatmaps for week, month and all-time activity; arrows/Tab change period, r refreshes and Escape closes without losing the draft. Slash commands and Tab completion; Enter submits; Shift+Enter adds a line; Escape closes a picker; two Escapes within 600 ms stop a run; Ctrl+C cancels a prompt or active run and exits when idle. Pickers support arrow keys and text search. Account switch/remove rows show only the short provider name and account name, such as codex · Personal, without status marks, authentication details, IDs or request counts. Reset windows and available credits appear as compact secondary metadata. Settings use a searchable list with values and short explanations, then a focused picker or input for the chosen setting. Keep the workspace header pinned above every picker and statistics/tool panel. At very short terminal heights it compacts to the original Psi identity and path. Effort shows only supported level labels, the slider, a clickable OVERKILL toggle at the right of the level line and symbolic key hints. Generic menus use a short title, filter, compact list and key hints, without explanatory paragraphs. /tools is a paged name grid. /reset uses a compact bottom panel with provider-reported reset dates/countdowns and explicit account selection. A second Enter confirms a banked reset; ambiguous outcomes retain a durable retry key. Claude resets open the provider Usage page. Budget, request limits, output tokens and Compaction model stay in Settings. Appearance updates immediately; execution settings queue until the next safe boundary. Sending a message scrolls to the newest transcript content and restores follow mode; background updates respect manual scrolling. Verified completion publishes the full final Markdown review, including scope, evidence, validation and limitations. Substantial reviews use numbered findings, supporting subheadings, source references and comparison tables; simple tasks remain proportionate. Responses use an inline bullet and two-column hanging indent, with Markdown source reflowing at the terminal width. User prompts use a chevron with the same hanging indent. Keep a single blank row between blocks; omit repeated assistant-name headings and response-phase captions. Consecutive read/search/fetch calls group under Exploring/Explored with a tree-indented action list. Commands use Running/Ran and a bounded indented output preview. Show failures, background job IDs and interrupted outcomes explicitly. Ctrl+T expands tool detail previews inline. A transient Thinking/Working row lives above the composer, never in saved conversation text. /name persists and locks a session title without clearing the conversation. The first prompt seeds the title and the model may refine it once, but never overwrites a user title. /directory <path> selects and persists the working directory, replacing the old workspace grant. No add/remove subcommands. Display directories inside the home as ~/path with forward slashes. A user send receives a 240 ms eased accent transition; an active response or tool uses a restrained accent pulse and stable-width status text. Streamed text is shown immediately, without a typewriter delay. The global motion timer runs at most 12.5 frames per second while work or send feedback is active, and stops when idle, disabled or closed, except while the user has explicitly enabled OVERKILL. OVERKILL increases border weight, adds a filled ON badge and moves a brighter accent across the borders, usage meter and original terminal mark. Input and usage waves use an 850 ms phase scale with a restrained 0.75–1.20 brightness range; the logo keeps its existing motion. Reduced motion makes these accents static. UI animations can be disabled in settings. The logo also has an explicitly requested, click-triggered 3D view. It opens a rotating, shaded Ψ mesh occupying at most half the terminal height and 52 columns, at 24 fps and exits on click or Escape without changing the prompt. `/logo` supplies a keyboard alternative. Stop its timer completely on close and exit. No animation plays on startup. Streamed output is coalesced into approximately 35ms render windows. UI retains at most 100 transcript components while session evidence remains on disk.

## Assets

`assets/psi.svg` is the repository identity: a bevel-tipped Ψ with a restrained extrusion. `assets/psi-wordmark.svg` adds custom geometric PSI lettering. `assets/hero.svg` and its PNG render are the GitHub banner. The terminal preserves its original small shaded mesh and wordmark. `npm run preview:brand` regenerates the vector/PNG assets using an installed browser.
